# Logistics Quest — สื่อการเรียนรู้โลจิสติกส์แบบหลายหน้า

เว็บสื่อการเรียนรู้ภาษาไทยที่พาผู้เรียนเดินทางผ่านบทเรียนสั้น 4 ด่าน พร้อมมินิเกมฝึกทักษะคั่นระหว่างด่าน ก่อนลงสนามเกมแบบทดสอบ 8 ข้อ ออกแบบให้เปิดใช้งานได้ง่ายผ่านเว็บเบราว์เซอร์ทั้งบนมือถือและคอมพิวเตอร์

## หน้าเว็บ

- `index.html` — หน้าแนะนำและแดชบอร์ดความคืบหน้า
- `lessons.html` — แผนที่รวมบทเรียนทั้ง 4 ด่าน
- `lesson-01.html` ถึง `lesson-04.html` — เนื้อหา บทสรุป ตัวอย่าง และคำถามทบทวนสั้น ๆ ของแต่ละบท
- `practice.html?stage=1` ถึง `practice.html?stage=4` — มินิเกมเรียงขั้นตอน คิด Load Factor เลือกเส้นทาง และตรวจ OTIF
- `practice.js` — ตรรกะมินิเกมทั้ง 4 ด่าน
- `challenge.html` — เกมทดสอบท้ายบท พร้อมเฉลยอธิบาย คะแนนแยกตามหัวข้อ เล่นซ้ำ และดาวน์โหลดผล
- `glossary.html` — คลังคำศัพท์โลจิสติกส์ 12 คำ

## เนื้อหาการเรียน

1. **ภาพรวมโลจิสติกส์** — การไหลของสินค้าและ Order Fulfillment
2. **ความจุและการบรรทุก** — Capacity Planning และ Load Factor
3. **การวางเส้นทาง** — Vehicle Routing Problem (VRP) และข้อจำกัดการส่งหลายจุด
4. **เวลาและตัวชี้วัด** — SLA, On-time Delivery, OTIF และ Cycle Time

## เกมทดสอบ

มินิเกมทั้ง 4 ด่านเปิดจากท้ายบทเรียนและย้อนเล่นได้โดยไม่จำกัดครั้ง ส่วนแบบทดสอบท้ายบทมี 8 คำถาม ข้อละ 10 คะแนน ไม่จับเวลา หลังเลือกคำตอบจะแสดงเฉลยและคำอธิบายทันที เมื่อจบเกมจะเห็นคะแนนรวม คะแนนแยกตามด่าน และดาวน์โหลดสรุปผลเป็นไฟล์ `.txt` ได้ คะแนนสูงสุด จำนวนครั้งที่เล่น บทเรียนที่ทำเสร็จ และมินิเกมที่ผ่านจะบันทึกใน `localStorage` ของเบราว์เซอร์ที่ใช้งาน

## วิธีเปิด

เปิด `index.html` ด้วยเว็บเบราว์เซอร์ แล้วใช้เมนูเพื่อไปยังแต่ละหน้า เว็บไซต์ใช้ไฟล์ HTML, CSS และ JavaScript ภายในโฟลเดอร์เดียว ไม่ต้องติดตั้งเครื่องมือเพิ่ม ฟอนต์ IBM Plex Sans Thai และ Space Grotesk โหลดจาก Google Fonts เมื่อเชื่อมต่ออินเทอร์เน็ต หากออฟไลน์ เว็บจะใช้ฟอนต์สำรองของเครื่อง

## เผยแพร่ด้วย GitHub Pages

โปรเจกต์นี้เป็นเว็บสแตติกและมี workflow สำหรับ GitHub Pages ที่ `.github/workflows/deploy-pages.yml` เมื่อนำไฟล์ขึ้น branch `main` ให้เปิด Settings → Pages ของ repository แล้วเลือก Source เป็น **GitHub Actions** จากนั้น workflow จะเผยแพร่เว็บเมื่อมีการ push เข้า `main`

## วัตถุประสงค์การเรียนรู้

- อธิบายขั้นตอนพื้นฐานตั้งแต่รับสินค้าไปจนถึงส่งมอบให้ลูกค้าได้
- คำนวณ Load Factor และพิจารณาข้อจำกัดด้านความจุได้
- อธิบายปัจจัยที่ใช้วางแผนเส้นทางส่งหลายจุดได้
- อ่านความหมายของ SLA, On-time Delivery และ OTIF ในสถานการณ์พื้นฐานได้
